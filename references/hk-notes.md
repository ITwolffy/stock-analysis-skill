# 港股特有事项

港股分析前必读。底稿(港股)结构与 A股不同:§1 股价+估值、§3.1 年度财务指标(英文科目)、
§3.2 利润表、§3.3 资产负债表(中文标准科目)、§4 公司概况、§5 数据缺口。

## 币种(最容易错的点)

- 股价与市值:**HKD**(底稿标注)
- 财务报表币种:**看 §3.1 的 CURRENCY 行**——腾讯、中兴等大批公司报表是人民币,中海油等是港元
- 百度估值的 PE/PB 已按其口径算好,直接用;**自算任何倍数前先对齐币种**
- HKD/CNY ≈ 0.92(约数,需要精确时 WebSearch 当日汇率)

## 英文科目映射(§3.1)

| 字段 | 含义 | | 字段 | 含义 |
|---|---|---|---|---|
| OPERATE_INCOME | 营业收入 | | ROE_AVG / ROE_YEARLY | 平均/年化净资产收益率 |
| OPERATE_INCOME_YOY | 营收增速% | | ROIC_YEARLY | 投入资本回报率 |
| GROSS_PROFIT | 毛利 | | DEBT_ASSET_RATIO | 资产负债率% |
| GROSS_PROFIT_RATIO | 毛利率% | | CURRENT_RATIO | 流动比率 |
| HOLDER_PROFIT | 归母净利 | | CURRENTDEBT_DEBT | 短期负债占负债比% |
| HOLDER_PROFIT_YOY | 归母增速% | | OCF_SALES | 经营现金流/收入% |
| NET_PROFIT_RATIO | 净利率% | | PER_NETCASH_OPERATE | 每股经营现金流 |
| BASIC/DILUTED_EPS | 基本/摊薄EPS | | BPS | 每股净资产 |
| TAX_EBT | 实际税率% | | EPS_TTM | TTM每股收益 |

利润表中文科目:「营业额」=营业收入,「经营溢利」=经营利润,「除税前溢利」=税前利润。

## 老千股特征(报告必须核对)

1. 反复**供股/合股**(拆细再合并,摊薄小股东)——WebSearch「公司名 供股 合股 历史」
2. 频繁改名、追逐热点概念
3. 大幅折让定向配售给关联方
4. 成交量长期低迷(底稿§1 月线成交额可查)——日均成交 <2000万HKD 加流动性警告
5. 大股东持股 <30% 且股权质押高
命中 ≥2 条:**直接在报告§0 标注「疑似老千股,回避」**,不必继续深挖

## 其他

- 披露节奏:中期报告 + 年度报告两披露,公告在披露易(hkexnews)
- 开曼/百慕大注册是常态(不是红旗);VIE 结构(腾讯/阿里)注意政策风险表述
- 核数师非四大≠问题,但小所审计 + 上述特征叠加时要写明
- 数据缺口(§5):股息率/股东变化/质押/公告无接口,WebSearch 补,报告中标注检索日期
